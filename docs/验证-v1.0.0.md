# 1.0.0 验证记录

文件转换核心沿用已经完成完整验证的实现：194项回归测试、92条直接转换方向及4个扫描/多页PDF额外用例全部通过；同时验证同格式批量、精确体积边界、损坏输入、路径安全和结果保存。

1.0.0统一应用、接口、Windows文件属性和发布标签的版本标识，并整理公开源码和文档。发布前核对转换核心源码与完整回归受测源码的SHA256一致，重跑原生工作台40组交互、解压和密码搜索18组检查、28条转换专项及动画AVIF验证。

原生检查覆盖圆标/圆盘/矩形切换、拖动、悬停、进度、全屏、调整大小、置顶同步、折叠说明、模态选项、批量和密码窗口。压缩包检查使用合成已知密码，不穷尽深度搜索的所有大范围。

完整测试的体积上限通过模拟文件大小验证，未创建多GB测试文件；读取进度另使用12 MB真实文件验证。兼容模式与单实例启动也已检查。

公开发行包按明确清单排除本地data、清理记录、本机日志、搜索进度和缓存。最终校验包含ZIP CRC、SHA256、受测EXE哈希、公开源码一致、依赖和版本号。

机器可读结果见[release-validation.json](release-validation.json)。测试均在Windows x64环境运行，日期以验证记录为准。
