# 图片与图像 · 内置引擎

| 组件 | 本次版本 | 用途 |
| --- | --- | --- |
| Pillow | 13.0.0 | JPG、PNG、TIFF、WebP、ICO、GIF 帧读取与图片编码 |
| pillow-heif | 1.8.1 | HEIC / HEIF 离线解码，Windows wheel 含所需解码库 |
| rawpy / LibRaw | 0.28.0 | 相机 RAW 识别、相机白平衡显影 |
| tifffile | 2026.11.12 | RAW 显影结果保存为 16 位 RGB TIFF |
| PyMuPDF | 1.26.7 | SVG 栅格化、图片嵌入与多图合并 PDF |
| imageio-ffmpeg | 0.8.1 | 提供随包 FFmpeg 可执行文件 |
| FFmpeg | 9.0.2 essentials / gyan.dev | GIF 动画编码为 H.264 MP4 |

这些组件随便携版分发，无需在目标电脑单独安装。实际安装版本记录在 requirements-lock.txt，第三方许可保留在 licenses/ 和内置组件目录。

FFmpeg 的实际构建和许可输出见本目录「验证-v1.0.0.md」中的检查说明与便携版 licenses/FFmpeg/。本次二进制由 imageio-ffmpeg 的 Windows wheel 提供，优先读取包内 binaries，转换时不依赖机器 PATH 中的 FFmpeg。

数据板块使用 Python JSON/CSV、PyYAML 6.0.3 安全加载器和 lxml。音视频板块复用同一内置 FFmpeg，用于容器检测、换封装、转码、音轨提取与动图截取，无需额外安装解码器或 ffprobe。
