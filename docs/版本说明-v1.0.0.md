# K文件处理台 1.0.0

Windows 10/11 x64 便携文件处理工作台，初始为可拖动圆形Logo，支持圆形与矩形工作台。

- 文档与办公、图片与图像、结构化数据、音视频提供92条直接转换方向。
- 解压与破译支持ZIP、RAR、7z、TAR、TAR.GZ、TAR.XZ及兼容第一分卷。
- 支持同格式多选、顺序批量转换、读取百分比和转换激光光圈。
- 文档、图片、结构化数据单次合计500 MB；音视频2 GB；压缩包5 GB；最多100个同格式文件。
- 独立说明窗口含简略和详细两页，详细说明六个一级目录、24个二级目录默认折叠。
- 窗口可置顶、拖动、缩放、全屏；密码窗口支持停止、续搜、最小化和全屏。

便携包包含所需引擎和运行库。解压后运行K文件处理台.exe，迁移时复制完整文件夹。结果、设置和搜索数据保存在本机data目录。
